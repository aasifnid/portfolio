One system, every page.

The single source of truth for the gradient theme. Built from the components in the home and case-study pages, rationalized to a strict grid so every page stays uniform on migration.

Type7 sizes only — 56 / 32 / 24 / 20 / 16 / 14 / 12. Two families: Space Grotesk (display) + Inter (body). Two weights each.
Color6 neutrals + 1 accent + 1 gradient. A separate 4-color data set for charts only.
No decimalsEvery font size is a whole, even number. No 12.5, no 17, no 15.5.
8-gridSizes, spacing and radius are multiples of 8 — 4 only where 8 is too coarse. Never odd.
One padding mathPage gutter 40 / 24. Section rhythm 104/72 (home) · 80/56 (case study). Cards 24 or 32.
MotionTwo eases, three durations (.2 / .3 / .5s). The bounce ease is reserved for the caricature.
