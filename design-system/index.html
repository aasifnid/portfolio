Accent color · use rules

Purple 4

#FF80F4 · contrast on white: 2.4:1 (fails WCAG for body)

Purple 4 is a highlight signal, not a text color. The single accent for marking interactive or important elements.

Use for

  • Fills — button bg, callout bg, swatch dots
  • Borders — insight left rule, active tab underline
  • Hover indicator — text shifts purple on hover (brief)

Don't use for

  • Persistent text on light surfaces (fails contrast)
  • Eyebrow labels, captions, body — use ink-3 instead
  • Active-state text — use ink + purple underline

Stroke system · 2 tiers, 2 roles

Tier 1 · Featured

67%

1px solid var(--color-ink) · top + bottom (or top only). Reserved for hero / closing blocks that anchor a section: .cs-stat-hero, .cs-transfer. Signal: "look here."

Tier 2 · Structural

Row 1 · 60% completion

Row 2 · 22% retention

1px solid var(--color-border) · hairline. For tables, rows, sub-blocks: .cs-method, .phase-table, .outcome-stats, .observation-block, .decision-item. Signal: "structural, scan past."

Rule: Section breaks use whitespace + numbered heading (no stroke). Borders are reserved for component-internal structure only. When the reader sees a dark line, it means "stop and look." When they see a light hairline, it means "row separation, keep moving."

Global rules · enforced site-wide

Sharp edges

All rectangular UI uses border-radius: 0. No exceptions for cards, buttons, badges, inputs, or speech bubbles. Only true circles (border-radius: 50%) are allowed — used for avatar photos, recommendation cards' LinkedIn overlay, and the chrome browser dots in the dashboard frame.

Mobile overflow guard

Every page sets html { overflow-x: clip } + body { overflow-x: hidden } globally. Prevents a recurring white sliver bug on mobile when any descendant overflows its container — case study image grids and the cs-next footer are common triggers.

Decision block .decision-item · typographic, no card chrome · title format "Decision N — Title text" (text-xl DM Sans 600) · with .decision-alts card-spread sub-block

Decision 1 — Tutor as observer, not director

Every selection belongs to the student. The tutor sees the same screen in real time but cannot tap or control anything.

Tutor role

Fully private

Read as abandonment. Tutor couldn't catch students who got stuck.

Tutor co-control

Overrode student autonomy. Defeated the point of self-led check-in.

Silent observer

Tutor sees the screen in real time but can't tap or control anything.

Decision alts · card spread .decision-alts-cards · 3-column grid · surface-2 fill on cards · 16px gap · picked card carries 2px accent border + ✓ checkmark badge in top-right corner · thumbnail area (.decision-alts-card-thumb) optional, sits flush at top with no inner stroke · mobile collapses to single column · used in: Feel Check (Decisions 1 Shape, 1 Visual style, 2 Vocabulary, 3 Routing, 4 Audio strategy)

Routing

Skip button

Felt like failure to the student. Defeated the purpose of asking.

Required answer (spec)

Students would make something up. Regulation would match the made-up answer, not the real state.

Curated routing

Accepts "I don't know" honestly. Shows activities that work without a named emotion.
